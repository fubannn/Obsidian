## 0. 你这 3 分钟要把哪 5 件事讲清楚

录之前心里有数，旁白就顺着这条线走，不会乱：

1. **C/S 架构**：服务员(server)管数据、顾客(client)来点单；
2. **TCP 连接**：客户端是"连进来"的，不是本地自己玩；
3. **抽签在服务器做**：不放回、不重复、重启不丢；
4. **协议 + 校验 + 鲁棒性**：14 字节报头、CRC32、黑盒攻击打不死；
5. **可选功能**：注册/登录/注销（时间不够就整段删）。

## 3. 逐字稿（把第 2 节的台词连起来的完整版，想一口气背这段）

> 老师您好，我抽到的是第 3 题：基于 socket API 的选题系统。我采用客户机/服务器模式，用 Python 实现，通过 TCP 通信。

> 先启动服务端。启动参数有两个必填的：选题数量 8 个，和座位表文件 seats.csv，里面是全班座位号与学号的对应关系。服务端启动后加载座位表，初始化 1 到 8 的选题池，然后开始监听。注意这个地址是 0.0.0.0 冒号 9999——意思是它监听本机所有网卡，局域网里任何一台能连到这台电脑的机器，都能作为一个客户端连进来抽签。这正是客户机/服务器模式里服务器该有的样子，它服务的不是自己这台电脑，而是整个网络里的客户机。

> 然后在另一个终端启动客户端，通过 TCP 连到服务器的 9999 端口。这里地址是 127.0.0.1，表示我自己这台电脑。演示环境里服务器和客户端在同一台机器上，所以连环回地址；原理上和从别的电脑连局域网 IP 完全一样。

> 先演示抽签。输入座位号 1。服务器先验证这个座位号在不在座位表里，通过以后，从剩余选题池里随机抽一个给你。同一个座位再抽一次，服务器识别出他已经抽过了，把原来的签号原样还给他——这就是一人一签，不会重复发放，也正是题目要求的"不放回采样"。

> 再演示查询。座位 1 已经抽过，查到的就是刚才那个选题号；座位 2 还没抽，服务器返回"尚未抽签"。查询只读不改，不碰选题池。

> 输入一个不存在的座位号 999，服务器校验后直接返回"错误座位号"，说明座位号的有效性验证是真实生效的。

> 查看剩余选题，还剩 7 个，具体是哪些号也列出来了。抽走一个，池子里就少一个，直观体现了不放回。

> 下面演示可选功能：注册、登录、注销。密码在服务端是用 PBKDF2 加盐哈希存的，不保存明文。

> 最后验证系统能不能扛住黑盒攻击。黑盒攻击的意思就是：假设一个客户端完全不懂协议，随便往服务器塞报文。这个脚本依次发七类非法报文——随机字节流、错误 magic、被篡改的、未知任务代码、非 JSON、超长长度、还有截断的报文。可以看到，服务器对每一类都是要么给明确的错误响应，要么安全断开连接；全部打完之后，我再用一条标准的 PING 问它一声，它还活着。原因是每一层都有校验：报头 magic、长度上限、CRC32 完整性、JSON 解析、任务代码白名单，而且每个连接的错误都隔离在它自己的线程里，不会拖垮整个进程。

> 以上就是全部演示。报告里对报文格式、字段语义、CRC32 完整性校验和抽签流程都做了详细说明。谢谢老师。

## 4. 可选加分项：真正的"跨电脑"远端演示

如果你手头正好有**第二台电脑 / 手机能连同一个 WiFi（和这台电脑同一局域网）**：

1. 在服务端这台电脑的 PowerShell 里查局域网 IP（任何一台设备都行）：
   ```powershell
   ipconfig
   ```
   记下"无线局域网适配器"里 `IPv4 地址`，形如 `10.x.x.x`（这台电脑实测是 `10.196.155.215`，以当次为准）。
2. 服务端命令**不用改**（`0.0.0.0` 已经监听所有网卡）：
   ```powershell
   py server.py --topics 8 --seats seats.csv --port 9999
   ```
3. 第二台设备上安装 Python 后，把 `selection_system` 文件夹拷过去，运行：
   ```powershell
   py client.py --host <第一台电脑的局域网IP> --port 9999
   ```
   接着照第 2 节的 ④~⑦ 做一遍。
4. 这时在 ③ 的台词处换一句：
   > "这次我换一台设备，用服务器的局域网 IP `10.196.155.215` 连进来，演示真正的跨机器、跨进程的远端调用。输入的座位号会被送到那台电脑的服务器进程里，抽签在它的内存里完成、写进它的 state.json，再把结果传回来。"

> 如果只有一台电脑，**不录这段也完全够分**——127.0.0.1 已经是"客户端和服务端两个独立进程之间的通信"，本身就满足 C/S 要求。别为了追求"看起来远"硬上两台设备，翻车风险高。
